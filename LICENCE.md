## 🧩 About

**2XKO ESP Menu** is a curated list of 2XKO open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, frame data display
- **Quality-of-Life Helpers** — move list browser, combo trial notes, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Frame Data Overlay — view startup, active, recovery frames in real time
- Hitbox Viewer — visualize attack and hurtbox hitboxes
- Combo Trial Notes — record and review combo sequences
- Playback Speed — adjust training playback for study (0.1x to 5x)

### Wallhack
- Move List Browser — browse character moves, specials, supers
- Custom UI Notes — organize overlay themes and layouts
- Input Display — show current input history on screen

### Aimbot
- Training Mode Notes — segment study on any character
- Dummy Control — set dummy behavior for practice scenarios
- Frame Step — advance frame by frame for precise study

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"2XKO.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
| `frame_data` | Boolean | `true` | Show frame data overlay |
| `hitbox_view` | Boolean | `false` | Show hitboxes |

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| Overlay not showing | Run as administrator, check hotkey conflict |
| Game crashes on launch | Disable safe_mode in config, update GPU drivers |
| Frame data not updating | Ensure game is in training mode, restart overlay |
| Input display lag | Lower overlay refresh rate in config |
| Antivirus warning | Add exclusion for the helper folder (false positive) |
